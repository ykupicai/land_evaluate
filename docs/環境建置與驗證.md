## 1. 分開兩個 Python

| 執行環境 | 用途 | 本次基準 |
|---|---|---|
| 系統 Python | 清冊、API、統計、簡報、pytest | Python 3.14.0；直接相依見 requirements-core.txt |
| QGIS 隨附 Python | make_maps、road_access、其他需要 qgis／osgeo 的工具 | QGIS 3.40.12 LTR，見 QGIS_VERSION |

`requirements-core.txt` 固定 18 個直接相依，`requirements-dev.txt` 另含 pytest。
這不是所有間接相依的完整 lockfile，也不是其他 Python 版本均已驗證的承諾。
未在本輪建立全新機器測試；安裝後須跑下面的健檢與測試。

新機器在專案根目錄建立獨立環境（不要對目前可用環境直接升級）：

```powershell
py -3.14 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
& .\.venv\Scripts\python.exe -X utf8 -m pytest tests/ -q
```

執行案件前可用 `.\.venv\Scripts\Activate.ps1` 啟用環境；若公司政策禁止啟用腳本，
直接使用上述 Python 完整路徑即可，不需修改安全政策。
不要把這份 requirements 灌進 QGIS，也不要用 pip 取代 QGIS 隨附的 qgis／GDAL。
簡報逐頁 QA 另需 LibreOffice；此工具不由 pip 安裝。

## 3. 機器專屬路徑

讀取順序：內建預設 → `config/paths.yaml` → `config/paths.local.yaml`。
最後一份已被 Git 忽略；只填需要覆蓋的非空值。YAML 的 Windows 路徑建議用單引號。

```yaml
qgis_prefix: 'D:\QGIS 3.40.12\apps\qgis-ltr'
skills_root: 'D:\land-tools\skills'
nas_gis_root: '\\server\share\gis圖資'
# 離線時可各自指定，不一定要跟著 NAS 根目錄
dem_path: 'D:\gis\twdtm20m_float.img'
breed_shp: 'D:\gis\養殖漁業生產區.shp'
```

`skills_root`、`nas_gis_root`、DEM 與養殖圖資支援相對專案根目錄的路徑。
QGIS 安裝位置與自訂 LUIMAP 色碼表建議填絕對路徑。
shp、DEM 的附屬檔案也須完整搬移；`doctor` 的存在性檢查不會逐一驗證它們。

## 4. 不改資料的檢查

```powershell
python -X utf8 scripts/doctor.py
python -X utf8 scripts/doctor.py --qgis --nas
python -X utf8 -m pytest tests/ -q
python -X utf8 scripts/case_inventory.py
```

- `OK`：該項檢查通過；套件僅查版本與模組位置、外部引擎僅查必要檔案。
- `WARN`：部分圖資缺少，需依案型判斷；不會自動下載。
- `SKIP`：未檢查，例如沒加 `--nas` 時跳過網路圖資。
- `FAIL`：環境有缺項；doctor 回傳非零狀態碼。

`--qgis` 會另開短命程序實際匯入 QGIS、GDAL、geopandas、yaml、openpyxl。
NAS 存在性檢查可能受網路等待影響。這些檢查不驗證遠端 API 當下可用性、
圖資時效／完整性、法律適用性或簡報視覺品質。
