# 新同事上手指南

> 這份文件是給第一次接手這套工具的人看的：要裝什麼、資料去哪拿、怎麼跑第一個案子。
> 跑熟之後，日常工作請改看 [CLAUDE.md](../CLAUDE.md)（交接主檔，權威來源）與
> skill `cadastral-map-pipeline`（流程總控，若你也用 Claude Code）。

## 這套工具在做什麼（30 秒版）

批次處理「帶土地清冊的公文/報告」，比對全台地籍，判斷能不能變更/容許使用，
出七張 A4 成果圖（全都市計畫區的案子自動變六張），最後產一份評估簡報 pptx。
詳見 CLAUDE.md 開頭的專案說明；圖面要自己微調時見
`docs/免AI批次流程操作手冊.md`「出圖張數會自動變動、以及要自己微調圖面時」。

## 1. 環境安裝清單

實際安裝指令、套件版本與換機器健檢見 [環境建置與驗證](環境建置與驗證.md)。
請新建隔離環境，不要直接升級目前可用的 Python 或 QGIS 套件。

| 項目 | 版本／備註 |
|---|---|
| **Python（系統）** | 需含 `geopandas`、`pyogrio`（開發機用 Python 3.14）。腳本大多用 `python -X utf8 scripts\xxx.py` 執行 |
| **QGIS** | **固定用 3.40.12 LTR**（機器上可能裝了 3.6~3.24 好幾版，全部不要用）。出圖類腳本要用它內建的 python：`"<QGIS安裝路徑>\bin\python-qgis-ltr.bat"`，不是系統 python |
| **LibreOffice** | 簡報 QA 用（pptx 轉 pdf 逐頁核對），`soffice.exe --headless --convert-to pdf` |
| **Git** | 版本控制；中文路徑操作見下方鐵則 |
| **PowerShell** | **Windows 下任何涉及中文字元/路徑的檔案操作一律用 PowerShell，不要用 Bash**（Bash 會弄壞中文路徑）。純程式執行兩者都可以，但養成習慣用 PowerShell 較不容易踩雷 |
| **Claude Code** | 非必要，但這套工具是設計成搭配 Claude Code／AI 協作跑的（見下方兩種跑法）。純指令跑不需要它 |

## 2. 拿程式碼

這個資料夾是 git repo，但**大型圖資與案件資料不進版控**（見 `.gitignore`）。
拿到的程式碼包只有 `scripts/`、`config/`、`styles/`、`tests/`、`docs/`、`.claude/rules/`、
`CLAUDE.md`——這些才是「工具」本身，放到你自己機器的任意路徑都可以（習慣上放
`Documents\Claude\Projects\大量圖資轉換工具\`，方便跟 CLAUDE.md 裡少數提到的
範例路徑對照）。

## 3. 拿圖資（★最花時間的一步，且無法透過 git 傳遞）

以下資料夾**全部 `.gitignore`、動輒數十 GB**，程式碼包不含這些。
**好消息：公司 NAS 上都有對應來源，直接從 NAS 複製即可**（2026-08-07 使用者提供並實地
驗證路徑存在、與本機同構）。

NAS 圖資根目錄（下表 `<NAS>` 代表這一段）：
```
\\192.168.1.134\Public-TN\3. 圖資\gis圖資
```

| 本機資料夾（放在專案根目錄下） | NAS 來源路徑 | 大略大小 | 用途 |
|---|---|---|---|
| `地籍圖資/` | `<NAS>\地段地籍圖資\各縣市\2022地籍` | ~26 GB | ⓪a′周邊地籍發現、③出圖 |
| `國土功能分區/` | `<NAS>\國土功能分區` | 數 GB | 主題3出圖 |
| `都市計畫/` | `<NAS>\都市計畫相關\全台\都市計畫` | 數百 MB | 都市土地案出圖 |
| `環境敏感相關/` | `<NAS>\環境敏感相關` | 數 GB | ③c環境敏感套疊圖 |
| `2021全台農田水利灌排/` | `<NAS>\產業相關\一級產業\農業\2021全台農田水利灌排` | 數十 MB | 灌排水道檢核 |
| `農地重劃區/` | `<NAS>\產業相關\一級產業\農業\農地重劃區` | 數十 MB | 選用檢核 |
| `2021 國道省道以外道路/` | `<NAS>\交通相關\2021 國道省道以外道路` | 數十 MB | 區位圖外擴基準 |
| `社福機構/` | `<NAS>\社福機構` | 數 MB | 社福機構 200 公尺距離條款 |
| `門牌坐標/` | **不從 NAS 取**（見下） | 數十 MB | 聚落判定 |

⚠ **`門牌坐標/` 是唯一例外，請用腳本自動下載，不要去 NAS 拿**：
```powershell
python -X utf8 scripts\settlement_check.py --download --county 臺南市
```
它會從各縣市民政局開放資料抓**最新年度**版本並寫 `.版本.txt`。NAS 上雖有
`<NAS>\各縣市基礎資料\臺南市\台南門牌地址(108)`，但那是 **108 年舊版且只有臺南**，
與本機這份（腳本抓的 114 年版）不是同一份資料，拿錯會讓聚落判定用到過期門牌。

⚠ **複製時資料夾要改成左欄的名稱**——NAS 上的資料夾名與本機不完全相同
（例：NAS `2022地籍` → 本機必須叫 `地籍圖資`）。這些名稱**寫死在
scripts/config/skill/docs 四處**（見 CLAUDE.md「東西該放哪」一節），
大小寫、全形/半形空格都要跟左欄一模一樣，不要自己改名。

⚠ 部分圖資夾內有 `.版本.txt`（如 `都市計畫/`、`社福機構/`），記錄版本、關鍵欄位與
**換新版時的注意事項**——這些檔案跟圖資一起被 Git 忽略，須隨圖資另行複製，
不能假設 clone 專案就會取得；換版時先比對來源與日期，不要盲目覆蓋。

**驗證資料到位**：跑一次 `pytest tests/ -q`，多數測試不吃圖資，但能先確認程式碼本身
沒問題；接著照第 5 節跑一個真實案子最準。

## 4. 拿外部引擎與流程 skill 檔

這套工具的流程知識有一部分寫在 Claude Code 的 skill 裡（`~/.claude/skills/`，
**不在這個 git repo 裡**，是獨立的一批資料夾）。與本工具相關的有這幾個：

```
cadastral-map-pipeline   ← 端到端總控，其他都是它呼叫的子 skill
cadastre-check           （⓪a 免登入取地籍）
landmark-to-parcel       （⓪a反查 座標／Google Maps 網址 → 地段地號）
parcel-roster-verify     （⓪ 清冊地號健檢，需登入時才用）
tcdgis-parcels-to-shp    （① 平台取官方地籍，需登入時才用）
ngis-sensitive           （⓪b 環敏 NGIS 套疊，正式程序）
nluz-landzone-query      （⓪c 國土功能分區逐筆查）
shp-xls-area-join        （② 屬性接回，備選路徑用）
parcel-map-sheet         （③ 出圖版面）
buffer-greenbelt         （Ⓒ 緩衝綠帶，開發許可案用）
parcel-briefing-deck     （④ 簡報產製）
env-sensitivity-check    （⓪b 備選①，離線 PDF 應免查初篩）
```

把這 12 個資料夾整個複製到你的 `C:\Users\<你的帳號>\.claude\skills\` 底下即可，
Claude Code 會自動辨識。也可用 `config/paths.local.yaml` 的 `skills_root` 指向其他位置。
**即使不用 AI，四組外部 Python 引擎仍是對應功能的必要相依**：`cadastre-check`、
`ngis-sensitive`、`nluz-landzone-query`、`env-sensitivity-check`。不能把整步跳過。
其他資料夾主要供 AI 流程與交接使用；純指令模式不需安裝 Claude Code 本身。

## 5. 跑第一個案子，驗證環境

**最小驗證（不需圖資、不需 QGIS，純測 API 連線）**：
```powershell
python -X utf8 scripts\cadastre_fetch.py fetch --county 臺南市 --town 善化區 `
    --section 善南段 --landnos 344 --out scratch_test --name 測試
```
成功會印出 1 筆 OK、寫出 shp。這一步能跑通，代表 Python 環境與內政部/農業部
免登入 API 都正常。跑完刪掉 `scratch_test/` 即可。

**完整驗證（需圖資＋QGIS）**：兩種跑法擇一——
- **有 Claude Code**：把案子丟進 `待評估資訊/`，跟 AI 說「跑某某案」，AI 會照
  CLAUDE.md 與 skill 的流程走。
- **純指令**：照 `docs/免AI批次流程操作手冊.md` 逐步下指令。

第一次跑建議找一個**筆數少、非都市土地容許使用**的案子（不用碰 TCDGIS 登入、
不用跑隔離綠帶），最快驗證整條產線通不通。

## 7. 開始用之前，兩件事要知道

1. **這套工具假設你懂空間規劃/土地使用**——它會幫你查資料、算距離、出圖，
   但○△╳的最終判斷、法規解讀仍需要你自己確認，尤其 CLAUDE.md 反覆強調的
   「先查衍古知識庫」「地方専屬指導原則」這類東西，工具查不到就是查不到，
   要靠人問。
2. **每案的實際輸出（STATE.md、簡報、圖）不會在程式碼包裡**——那是案件資料，
   跟大型圖資一樣不進版控。你自己跑出來的東西，會長在你自己機器的 `outputs/`。
